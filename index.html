01 · Getting Started

Quick Start setup in 4 steps

Download the .rbxm above and insert it into Roblox Studio. Widgengine can be placed anywhere the client has access — ReplicatedStorage, StarterPlayerScripts, inside a LocalScript, wherever. As long as the LocalScript can reach it via require(), it will work.

valid placement locations 
ReplicatedStorage
└── Widgengine          ← recommended shared location
    └── UIBuilder

StarterPlayerScripts
└── Widgengine          ← also fine
    └── UIBuilder

LocalScript
└── Widgengine          ← fine if only used by one script
    └── UIBuilder

  • Download and insert the .rbxm into your place. UIBuilder is already nested inside — no extra setup needed.

  • Move Widgengine to any location accessible by a LocalScript. ReplicatedStorage is recommended when multiple scripts need it.

  • Require Widgengine from a LocalScript. The module warns and returns nil if required from the server.

  • Call Widgengine.New("Title") and chain your labels, buttons, and containers.

lua · LocalScript 
-- from ReplicatedStorage (shared)
local Widgengine = require(game.ReplicatedStorage.Widgengine)

-- or from script-relative path
local Widgengine = require(script.Parent.Widgengine)

local widget = Widgengine.New("Debugger")

widget
  :AddLabel("FPS",  getFPS)
  :AddLabel("Ping", getPing, false)
  :AddButton("Respawn", function() player:LoadCharacter() end)

widget:AddContainer("Movement")
  :AddButton("Fly",    toggleFly)
  :AddButton("Noclip", toggleNoclip)
02 · Architecture

Core Concepts how it works

Widget Identity

Each widget is registered by its title string in Widgengine.Widgets. Calling .New() twice with the same title logs a warning and returns nil. Titles are also set as the Name property of the UI frame.

List vs Grid Layouts

The root widget container uses UIListLayout — labels and buttons stack vertically as full-width rows. When you call :AddContainer(), a sub-section is created using UIGridLayout with cells fixed at 74×36px, wrapping horizontally.

AutomaticSize

Both the root container and every sub-container use AutomaticSize = Y, so the widget's height is always exact. A GetPropertyChangedSignal("AbsoluteSize") listener keeps the border Stroke frame perfectly in sync — no manual height math anywhere.

Dropdown Toggle

The small arrow in the title bar toggles between expanded (Dropped = true) and collapsed. When collapsed, the Container is hidden and the Stroke border shrinks to match just the title bar height. The arrow rotates 180°.

ℹ

Widgengine is client-only. Any .New() call from a server Script produces a warning and returns nil immediately. Always place the require inside a LocalScript.

Method Chaining

All methods return self, so you can chain calls fluently. The one exception is :AddContainer(), which returns a new SubContainer — intentionally breaking the chain so you can populate the grid separately.

Widgengine API · Static

Widgengine.New creates a widget

static
Widgengine.New(WidgetTitle: string) → Widgengine?
↩ Widgengine | nil

Creates a new draggable widget panel registered under WidgetTitle. Returns the Widgengine object on success. Returns nil if called from the server, or if a widget with that title already exists.

The widget is immediately rendered in PlayerGui.DebugGui, visible and expanded by default.

ParameterTypeDescription
WidgetTitlestringUnique name shown in the title bar. Used as the registry key and the Frame's Name property.
lua 
local widget = Widgengine.New("Debug")

if not widget then return end -- server or duplicate
Widgengine API · Method

:AddLabel key / value row

method
widget:AddLabel( itemName: string, callback: ()→string, useRunService?: boolean ) → Widgengine
↩ self — chainable

Appends a full-width key/value row to the widget. The left side shows itemName as a static label; the right side is updated by calling callback on a schedule.

ParameterTypeDescription
itemNamestringLeft-side label text. Also used as the instance Name.
callback()→stringCalled repeatedly. Return value is shown on the right side of the row.
useRunServiceboolean?Default true. When true, fires every frame via RenderStepped. When false, polls every 0.5s. Use false for expensive reads.
💡

Pass false as the third arg for values that don't need frame-rate updates — server stats, inventory counts, configuration values.

lua 
widget
  :AddLabel("FPS", function()
      return tostring(math.floor(1 / deltaTime))
  end)  -- every frame (default)

  :AddLabel("Ping", function()
      return tostring(ping) .. " ms"
  end, false)  -- every 0.5s
Widgengine API · Method

:AddButton full-width button

method
widget:AddButton( itemName: string, callback: ()→nil ) → Widgengine
↩ self — chainable

Appends a full-width clickable button to the widget list. Buttons include hover and press colour tweens driven by TweenService. Styled with a UICorner (4px) and an accent UIStroke.

ParameterTypeDescription
itemNamestringText shown on the button face. Also the instance Name.
callback()→nilCalled once per click via Activated.
lua 
widget
  :AddButton("Respawn", function()
      player:LoadCharacter()
  end)
  :AddButton("Kill", function()
      player.Character.Humanoid.Health = 0
  end)
Widgengine API · Method

:AddContainer grid sub-section

method
widget:AddContainer( containerName: string ) → SubContainer
↩ SubContainer — NOT self

Inserts a titled sub-section that uses UIGridLayout instead of a list. Returns a SubContainer object. Cells are 74×36px and wrap horizontally to fill available width.

Multiple containers can be added to a single widget. Each appears as a labelled section with a 1px accent divider at its top edge.

ParameterTypeDescription
containerNamestringSection header text (accent colour) and instance Name.
⚠

:AddContainer() returns a SubContainer, not Widgengine. The chain is intentionally broken. Store the result or chain immediately to populate the grid.

lua 
local movement = widget:AddContainer("Movement")
movement
  :AddButton("Fly",    toggleFly)
  :AddButton("Noclip", toggleNoclip)
  :AddButton("Speed",  toggleSpeed)

-- Multiple containers per widget is fine
widget:AddContainer("World")
  :AddButton("Day",   setDay)
  :AddButton("Night", setNight)

SubContainer:AddButton grid cell button

class
container:AddButton( itemName: string, callback: ()→nil ) → SubContainer
↩ self — chainable

Adds a button cell to the grid. Same hover/press tween behaviour as the root :AddButton(). Cell size is owned by the UIGridLayout (74×36px).

ParameterTypeDescription
itemNamestringCell label text and instance Name.
callback()→nilCalled on Activated.
SubContainer API · Method

SubContainer:AddLabel grid cell label

class
container:AddLabel( itemName: string, callback: ()→string, useRunService?: boolean ) → SubContainer
↩ self — chainable

Adds a read-only label cell to the grid. Defaults useRunService to false (unlike the root :AddLabel() which defaults to true). Grid labels are typically less performance-critical, so polling every 0.5s is the safer default.

ParameterTypeDescription
itemNamestringLabel title and instance Name.
callback()→stringReturns the cell's display value.
useRunServiceboolean?Default false. Pass true for per-frame updates.
Internal Module

UIBuilder instance factory

UIBuilder is the internal template factory required automatically by Widgengine. It should sit as a child ModuleScript. You do not interact with UIBuilder directly in normal usage — this section is for contributors and anyone extending the system.

ℹ

Each Build function increments a module-level index counter by 10000. This ensures ZIndex layering is always correct for multiple stacked widgets.

UIBuilder · Function

BuildWidget root frame + chrome

static
UIBuilder.BuildWidget() → Frame

Creates the full widget frame hierarchy and injects it into PlayerGui.DebugGui (creating the ScreenGui if it doesn't exist). Returns the root Title Frame.

ChildTypeRole
t_textTextLabelWidget title text, left-aligned in the bar
DropdownImageButtonCollapse / expand toggle arrow
StrokeFrame + UIStrokeAccent border spanning full widget height
ContainerCanvasGroupContent area; AutomaticSize Y, UIListLayout
UIDragDetectorUIDragDetectorMakes the widget draggable by its title bar
UIBuilder · Function

BuildLabel key / value template

static
UIBuilder.BuildLabel() → TextLabel

Returns a TextLabel (the root element) configured for value display (right-aligned). It contains a child TextLabel named Title that displays the key (left-aligned). Both are capped at MaxTextSize = 18 via UITextSizeConstraint.

The caller sets Name, Title.Text, and Size after receiving the template.

UIBuilder · Function

BuildButton unsized button template

static
UIBuilder.BuildButton() → TextButton

Returns a TextButton with a UICorner (4px), an accent UIStroke, and AutoButtonColor = false. No size is set — the caller provides size so the same template works as both a full-width list row and a compact grid cell.

Hover and press tweens are attached externally by attachButtonEffects() inside Widgengine, not UIBuilder.

UIBuilder · Function

BuildSubContainer grid section wrapper

static
UIBuilder.BuildSubContainer() → Frame

Returns a Frame wrapper with AutomaticSize = Y. The wrapper grows vertically as cells are added. Children:

ChildTypeRole
DividerFrame1px accent-tinted separator at section top
HeaderTextLabelSection name in accent colour, 17px tall
InnerCanvasGroupGrid canvas; UIGridLayout with 74×36px cells, 4px gap, AutomaticSize Y
Guide

Method Chaining fluent api patterns

Every method on both Widgengine and SubContainer returns self. The single exception is :AddContainer(), which returns a new SubContainer. This lets you write highly readable setup code in one expression.

lua · chaining patterns 
-- All root items in one chain from .New()
local widget = Widgengine.New("Performance")
  :AddLabel("FPS",    getFPS)
  :AddLabel("Ping",   getPing,   false)
  :AddLabel("Memory", getMemory, false)
  :AddButton("GC",    collectGarbage)

-- AddContainer returns SubContainer — new chain
widget:AddContainer("Graphics")
  :AddButton("Shadows", toggleShadows)
  :AddButton("Fog",     toggleFog)
  :AddLabel("Quality", getQuality)

-- Second container on same widget — still fine
widget:AddContainer("Audio")
  :AddButton("Mute", toggleMute)
  :AddLabel("Vol",   getVolume)
💡

You only need to store the widget reference if you plan to call :AddContainer() after the initial chain. If everything is set up in one go, the return value of .New() can be discarded.

Full Examples complete scripts

Performance Monitor

lua · performance monitor 
local RunService = game:GetService("RunService")
local Stats      = game:GetService("Stats")
local Widgengine = require(script.Parent.Widgengine)

local lastTime = tick()
local fps = 0

RunService.RenderStepped:Connect(function()
  local now = tick()
  fps = math.floor(1 / (now - lastTime))
  lastTime = now
end)

Widgengine.New("Perf")
  :AddLabel("FPS",    function() return tostring(fps) end)
  :AddLabel("Ping",   function()
      return tostring(Stats.Network.ServerStatsItem["Data Ping"].Value) .. " ms"
  end, false)
  :AddLabel("Heap",   function()
      return string.format("%.0f MB", Stats.DataModel.DataModelStats.TotalMemoryUsed / 1024)
  end, false)

Full Debug Panel

lua · debug control panel 
local Players    = game:GetService("Players")
local Lighting   = game:GetService("Lighting")
local Widgengine = require(script.Parent.Widgengine)

local player = Players.LocalPlayer

local widget = Widgengine.New("Debug")
  :AddLabel("Position", function()
      local root = player.Character and player.Character.HumanoidRootPart
      if not root then return "—" end
      local p = root.Position
      return string.format("%.0f, %.0f, %.0f", p.X, p.Y, p.Z)
  end)
  :AddButton("Respawn", function() player:LoadCharacter() end)

widget:AddContainer("Cheats")
  :AddButton("Fly",      toggleFly)
  :AddButton("Noclip",   toggleNoclip)
  :AddButton("Inf Jump", toggleInfJump)

widget:AddContainer("World")
  :AddButton("Day",   function() Lighting.TimeOfDay = "12:00:00" end)
  :AddButton("Night", function() Lighting.TimeOfDay = "00:00:00" end)
  :AddLabel("Time",  function() return tostring(math.floor(Lighting.ClockTime)) .. "h" end)
